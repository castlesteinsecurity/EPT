GPS requer HTTPS

O navegador bloqueia o acesso ao GPS em páginas abertas por arquivo local (file://) ou HTTP sem criptografia. Isso é uma restrição de segurança do navegador, não um erro do sistema.

Para o GPS funcionar, o arquivo precisa estar em um servidor HTTPS. A forma mais fácil é usar o GitHub Pages — é grátis e automático:

Suba os arquivos em um repositório público → Settings → Pages → Branch: main → Save

O link gerado (https://seu-usuario.github.io/rota-segura/motorista.html?bus_id=402) vai funcionar no celular.

Enquanto isso, use o modo Manual abaixo para testar o envio ao Supabase.
